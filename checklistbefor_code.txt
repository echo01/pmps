Step 4.17 — จุด Debug ถ้า Health API ไม่ผ่าน

กรณี 1: DATABASE_URL is required
แปลว่า .env ไม่ถูกโหลด หรือไม่มี DATABASE_URL
ตรวจด้วย:
PowerShell
node -e "require('dotenv').config(); console.log(process.env.DATABASE_URL)"

กรณี 2: password authentication failed
แปลว่า username/password PostgreSQL ผิด
ให้ตรวจ .env:
DATABASE_URL=postgres://postgres:your_password@localhost:5432/production_db


กรณี 3: database "production_db" does not exist
แปลว่าชื่อ database ผิด หรือยังไม่ได้สร้าง DB
ตรวจด้วย psql:
psql -U postgres -h localhost -p 5432 -l

กรณี 4: Port 3000 already in use
เปลี่ยน .env:
PORT=3001
แล้วรันใหม่:
npm run dev
